# Brillare Scholars — website draft

A responsive, buildless homepage with navy accents, original SVG architectural art, scroll reveals, reduced-motion support, and accessible FAQ disclosures.

## Preview
Open index.html in a browser. No installation or build required. Fonts load from Google Fonts; system fonts are the fallback.

## GitHub
Create a new repository named brillare-scholars-draft and add index.html and this README at its root. For an optional GitHub Pages preview, choose Settings > Pages > Deploy from a branch, main, / (root). Keep the existing custom domain unchanged while reviewing the draft.

Enrollment and student portal links intentionally open the current Brillare Scholars website. Workshop contact links open an email draft. There is no new enrollment backend or student authentication system.

Copy is based on the existing homepage and About page. Artwork is illustrative. Review copy and branding before replacing the existing site.

Validation: JavaScript syntax and internal anchor checks passed. Desktop appearance and FAQ expansion checked in browser. Mobile breakpoints are implemented but not device-tested.
