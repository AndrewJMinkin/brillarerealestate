# Brillare Scholars — website

Single-page, buildless site. Open `index.html` in a browser; no install needed.

- `index.html` — the whole page (HTML, CSS, JS)
- `logo.png` — the Brillare Scholars logo (transparent PNG, no background fill)

Sections follow the original site: Home, By The Numbers (count-up), Our Services, Mission, About, The Team, Enroll Now, Join Us, footer.
